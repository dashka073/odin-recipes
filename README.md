Мой проект - рецепты.
Это мой второй проект HTML. Данная работа выполнена в качестве практики с курса The Odin Project.
Я создам базовый веб-сайт с рецептами для отработки своих HTML-навыков.

* Добавление ссылок на другие страницы
* Вставка изображений
